# SEGA Scripts

## Quick Start

**⚠️ IMPORTANT**: Read [BUILD_SCRIPTS_USAGE.md](./BUILD_SCRIPTS_USAGE.md) before using any build scripts!

The ecosystem has two types of projects:
- **Demo Apps** (landing-only) → Use `build-landing-apps.sh`
- **Development Apps** (full stack) → Use each project's `docker-compose.yml`

**Never** use `build-landing-apps.sh` for development apps (e.g. atlas, hermes).
